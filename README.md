# 뿡! 카드게임

꼴찌를 면하는 파티 카드게임 **뿡**을 AI 상대와 브라우저에서 해 보는 웹앱입니다.

- **가족판 · 할머니 생신잔치**: 정직한 구조. 먹고 마시다 가스가 16을 넘으면 양옆이 "뿡!"을 외칩니다.
- **회식판 · 술자리를 버텨라**: 술잔 밑으로 카드를 흘리고, 의심하고, 들키는 블러핑 구조.
- 처음이면 시작 화면의 **"처음이에요 (튜토리얼)"** 로 설명 슬라이드와 코치가 붙는 연습 판을 해 보세요.

빌드 과정 없는 정적 사이트입니다 (`index.html`, `app.css`, `g1.js`~`g3.js`). 주소 끝에 `#selftest`를 붙이면 AI끼리 2,400판을 돌려 규칙 엔진을 점검합니다.
